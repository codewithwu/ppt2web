# fonts/local —— 放商用字体的真身

转换器优先用这里的字体文件画字形轮廓（**字形与原稿完全一致**）。

## 怎么放

把字体文件丢进这个目录就行，**文件名不用严格等于 PPT 里的字体名**：

| PPT 里的 typeface | 可以用的文件名 |
|---|---|
| `阿里巴巴普惠体` | `阿里巴巴普惠体.ttf`、`阿里巴巴普惠体-3.0 55 Regular.ttf` |
| `思源宋体 CN Heavy` | `思源宋体 CN Heavy.ttf`、`思源宋体CNHeavy.otf` |
| `演示夏行楷` | `演示夏行楷.ttf` |

匹配规则：规范化（去空格/连字符/下划线、转小写）后**完全相等**优先；
否则按"文件名以字体名开头"匹配；多个候选时挑字重最接近的那个。

## 注意

- **这些文件不进版本库**（`.gitignore` 已排除）—— 商用字体的授权不随代码分发。
- 真身**缺字形**时（常见：中文字体没有西文）会**逐字符**回落到替代字体，
  不会让整个形状退回 HTML 文字。
- 放进去之后重跑 `convert`，`manifest.json` 的 `localFonts` 里就会出现它，
  `verify` 也会相应地把字体门禁从"回落清单"改成"真身"。
